# PDF Tools

Free online PDF tools - Merge, Split, Compress, Convert, Edit PDFs. All processing happens in your browser.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Features

- 21 PDF tools (12 fully working, 9 coming soon)
- Client-side processing — files never leave your device
- Sejda-style inline PDF editor
- Responsive design with Tailwind CSS
- Built with Next.js 16, TypeScript, pdf-lib, pdfjs-dist

## Working Tools

- Merge PDF, Split PDF, Compress PDF, Rotate PDF
- PDF to JPG, JPG to PDF
- Watermark PDF, Page Numbers
- Organize PDF, Crop PDF
- Edit PDF (inline text, shapes, whiteout)
- Sign PDF (draw or type signature)
